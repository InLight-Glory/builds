# 📈 Vessels of Sanctuary - Project Roadmap

**Version:** 1.0 (As of July 22, 2025)

## Overview
This document outlines the high-level, long-term development plan for Vessels of Sanctuary. It is divided into major phases, each with a clear set of goals.

---

## Phase 1: Foundation (Current)
**Focus:** Core Gameplay & Game Feel.

**Goals:**
- Implement and polish the client-side experience.
- Prove that the Echo System is fun and intuitive.
- Establish the foundational code for player characters and controls.

**Key Features:**
- Playable character
- `WASD` movement
- Camera controls
- Echo System swap

---

## Phase 2: Vertical Slice
**Focus:** End-to-End Gameplay Loop.

**Goals:**
- Create a small, functional section of the main game map.
- Implement a basic `Node.js` server for multiplayer connectivity.
- Enable a `1v1` match with a win condition.

**Key Features:**
- Basic networking
- Combat system (health, damage)
- One working ability per Vessel
- Simple item system

---

## Phase 3: Content Expansion & Alpha
**Focus:** Building out the full game experience.

**Goals:**
- Complete the `5v5` "Sanctuary Assault" map.
- Develop a roster of 10 playable Vessels.
- Implement all core game modes (`PvP` & `PvE`).

**Key Features:**
- Matchmaking
- Lobbies
- Full item shop
- AI minions and jungle monsters

---

## Phase 4: Beta & Polish
**Focus:** Balance, bug fixing, and community feedback.

**Goals:**
- Conduct closed and open beta tests.
- Refine game balance based on player data.
- Implement social features (friends list, guilds).

**Key Features:**
- Ranked mode
- Player progression system
- Cosmetic store
