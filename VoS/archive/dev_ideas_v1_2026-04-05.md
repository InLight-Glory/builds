## Ideas

### 1. Camera-Facing Health Bars (Billboarding)

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | XS |
| **Status** | 💭 Idea |

**Description:** Currently, TargetDummy health bars are `PlaneGeometry` meshes that face a fixed direction. They should billboard (always face the camera) so they're readable from any angle. This is a small quality-of-life fix that improves visual clarity during gameplay.

### 2. Enemy AI System

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | L |
| **Status** | 💭 Idea |

**Description:** The game currently only has a static TargetDummy. Adding basic enemy AI (patrol, chase, attack behaviors) would transform the prototype from a combat sandbox into an actual gameplay loop. Could start with a simple state machine (idle → chase → attack → retreat) and expand from there.
