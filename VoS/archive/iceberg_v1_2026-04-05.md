# Iceberg - Vessels of Sanctuary (VoS)

## L1 - Pages (Project Map)

### Project Summary

**Vessels of Sanctuary (VoS)** is a team-based Action MOBA prototype built with Three.js (WebGL). Set in a sci-fi world called "Gray-Earth," shattered by a cataclysm called "The Fracture," players select two "Vessels" (legendary characters) and can swap between them mid-combat with a cooldown mechanic. The game uses an isometric orthographic camera with low-poly humanoid models and real-time combat.

### Tech Stack

| Layer | Technology |
| :--- | :--- |
| Frontend | Vanilla JS + Three.js (r128) via CDN |
| Rendering | WebGL (THREE.WebGLRenderer) on HTML5 Canvas |
| Camera | Orthographic isometric (45-degree offset) |
| Data | JSON flat-file (`characterData.json`) |
| Backend | None (client-only prototype) |
| Build | No build step — ES6 modules loaded natively |

### Organizational Conventions

- **ES6 Modules**: All game logic uses `import`/`export` with `type="module"`.
- **Class-per-file**: Each class occupies its own `.js` file named after the class.
- **Folder-by-domain**: `vessels/`, `abilities/`, `npcs/` group by game domain.
- **Embedded CSS**: All styles live in `<style>` blocks within `index.html` — no external stylesheet.

| Action | Triggers | Result |
| :--- | :--- | :--- |

## L4 - Data & Workflows

### Data Sources

| Source | Path | Purpose |
| :--- | :--- | :--- |
| Character Config | `characterData.json` | Defines 7 playable vessels with stats, abilities, colors |

### Character Data Schema

Each character object:
```json
{
    "id": number,
    "name": string,
    "type": "guardian" | "marksman",
    "color": number (hex),
    "desc": string,
    "size": number,
    "speed": number,
    "primary": "Projectile" | "Charge" | "Melee" | "Psychic",
    "primaryCooldown": number,
    "secondary": "Projectile" | "Charge" | "Melee" | "Psychic",
    "secondaryCooldown": number
}
```

### Stat System

| Archetype | Base HP | Base Mana | Base AD | Base Armor | Growth Pattern |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Guardian | 650 | 300 | 55 | 40 | High HP/Armor growth |
| Marksman | 580 | 280 | 65 | 28 | High AD/AS growth |

### Core Gameplay Workflow

```
Player selects 2 vessels → startGame()
  → Vessel instances created with stats from characterData.json
  → Game loop (animate) begins
    → Each frame:
      1. Raycaster calculates mouseWorldPosition on ground
      2. Active vessel updates (movement + rotation)
      3. Projectiles update (collision checks vs damageableNpcs)
      4. Camera lerps toward active vessel
      5. HUD updates (cooldown, stats)
```

### Vessel Swap Workflow

```
Player presses Shift
  → Check elapsed time >= swapCooldown (5s)
  → Save position/rotation of current vessel
  → Hide current, show other
  → Copy position/rotation to new active vessel
  → Record swap time for cooldown UI
```

### Damage Workflow

```
Ability.execute() → creates Projectile
  → Projectile.update() each frame
    → Swept-segment collision check (XZ plane) vs targets
    → On hit: target.takeDamage(damage) → health bar update
    → Projectile destroyed after hit, range, or lifetime
```

## L5 - The Deep

### Collision Detection

- Uses **swept-segment collision** (not point-vs-circle) to handle high-speed projectiles passing through targets between frames.
- `closestPointOnSegment2D()` static method on `Projectile` class.
- `hitForgiveness = 0.75` added to projectile radius to compensate for isometric perspective making depth ambiguous.
- Vertical gating: projectiles only collide within half-height of target body.

### Camera System

- Orthographic camera with `d = 25` frustum size.
- Camera offset: `(25, 25, 25)` — true isometric angle.
- Smooth follow via `camera.position.lerp(targetPosition, 0.1)`.
- Camera-relative movement: WASD directions derived from `camera.getWorldDirection()`.

### Visual Style

- Bright daytime scene with sky-blue background (`0x87CEEB`).
- Multi-light setup: ambient (warm), directional (sun), fill (cool), hemisphere (sky-ground blend).
- PCF soft shadow maps at 2048x2048 resolution.
- Fog from 80-200 units matching sky color for depth fadeout.
- Ground: bright grass (`0x7EC850`) with translucent grid overlay.
- Scenery: procedural trees (trunk + 3-layer icosahedron canopy), bushes, and rocks with `flatShading`.

### Rendering

- Three.js r128 via CDN (no npm/build step).
- `requestAnimationFrame` loop with `THREE.Clock` delta-time.
- Shadows: `PCFSoftShadowMap`, directional light shadow camera covers -80 to 80 units.
- No post-processing pipeline.

### Model Construction

- All character models built from basic THREE.js geometries (BoxGeometry, IcosahedronGeometry).
- Guardian archetype: wider torso, larger head, thicker limbs.
- Marksman archetype: slimmer proportions.
- `flatShading: true` on all materials for low-poly aesthetic.

### Map Boundaries

- 250x250 unit ground plane.
- Player movement clamped to `mapBounds - 1` (124 units from center).
- Scenery scattered from -90 to +90 units.

### Known Limitations

- No multiplayer networking (client-only prototype).
- No save/load system.
- No enemy AI — only a static TargetDummy that respawns after 3s.
- No audio system.
- Health bars use `THREE.PlaneGeometry` — always face one direction, not camera-aligned.
- External texture dependency (`threejs.org` grass texture removed — now using solid color ground).
