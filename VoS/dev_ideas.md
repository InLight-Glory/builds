# Dev Ideas - Vessels of Sanctuary (VoS)

*A shared brainstorming ledger for feature proposals, scope discussions, and architectural explorations.*

---

## Ideas

### 1. Lane Turrets

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | M |
| **Status** | 💭 Idea |

**Description:** Classic MOBA turrets placed along each lane between the bases. Turrets would auto-target enemy minions/vessels within range, dealing damage over time. Destroying turrets opens up the lane. Could reuse the nexus tower visual style but smaller.

---

### 2. Gold & Item Shop System

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | L |
| **Status** | 💭 Idea |

**Description:** Earning gold from minion last-hits and jungle kills, spent at a shop in the base. Items would modify vessel stats (AD, armor, speed, etc.). Core progression loop for a MOBA — without it the game lacks in-match scaling incentives beyond level-ups.

---

### 3. Minimap

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | M |
| **Status** | 💭 Idea |

**Description:** A small top-down minimap in the corner showing lane positions, minion waves, and player location. Essential for MOBA map awareness. Could render as a secondary orthographic camera to a small canvas overlay.

| Field | Value |
| :--- | :--- |
| **Proposed By** | AI Session |
| **Date Added** | 2026-04-05 |
| **Scope Estimate** | S |
